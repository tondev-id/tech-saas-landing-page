Tech - SaaS Landing Page
The project focuses on practicing landing page structure, responsive layouts, semantic HTML, reusable UI patterns, and creating a clean user experience across different screen sizes.

Features:
- Responsive navigation
- Hero section with primary CTA
- Feature sections
- Product/value proposition sections
- FAQ section
- Responsive footer
- Mobile-friendly layout
- Responsive behavior across desktop, tablet, and mobile screen sizes

Built With: 
- HTML
- CSS
- JavaScript
- Netlify

Through this project, I practiced:
- Writing semantic HTML
- Building responsive layouts with CSS
- Working with Flexbox and CSS Grid
- Designing responsive navigation
- Deploying a static website

This project is part of my ongoing journey to improve my frontend development skills through hands-on projects.
I'm continuously learning by building websites, experimenting with different UI patterns, and improving my understanding of modern frontend development.
